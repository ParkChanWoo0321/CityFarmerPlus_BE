**도시농부플러스**는 충청북도에서 운영 중인 **충북형 도시농부 사업**의 신청, 모집, 매칭 과정을 디지털화한 서비스입니다.

현재 도시농부 사업은 농촌의 일손 부족 문제를 해결하기 위한 좋은 정책이지만, 실제 운영 과정에서는 전화, 문자, 수기 관리 중심으로 진행되는 경우가 많습니다.

도시농부는 교육을 이수한 뒤 중개센터에 전화로 신청해야 하고, 농가는 일손이 필요할 때 직접 연락하여 인력을 요청해야 합니다. 이 과정은 참여자에게 번거롭고, 농가 입장에서도 모집 글 작성이나 신청 관리가 어렵다는 문제가 있습니다.

**도시농부플러스**는 이러한 문제를 해결하기 위해 도시농부와 농가가 직접 플랫폼에서 신청, 모집, 수락, 근무 정보 확인을 할 수 있도록 돕습니다. 또한 생성형 AI를 활용하여 농가가 간단한 정보만 입력해도 모집 글을 자동으로 작성할 수 있도록 지원합니다.

## 🎯 프로젝트 목표

* 전화와 문자 중심의 도시농부 신청 절차를 온라인으로 전환
* 도시농부와 농가가 직접 연결될 수 있는 플랫폼 제공
* 농가의 일손 모집 글 작성 부담 완화
* AI를 활용한 모집 공고 작성 및 작업 안내 기능 제공
* 도시농부의 근무 정보 접근성 향상
* 농촌 일손 부족 문제 해결에 기여

## 🧩 문제 상황

충북형 도시농부 사업은 도시민이 농촌 일손 부족 문제 해결에 참여할 수 있는 좋은 정책입니다.

하지만 기존 방식에는 다음과 같은 문제가 있습니다.

* 도시농부 신청 과정이 전화와 문자 중심으로 이루어짐
* 교육 이수 후에도 별도로 전화 신청과 매칭 절차가 필요함
* 농가는 일손 모집을 위해 직접 연락하거나 설명해야 함
* 고령 농업인은 모집 글 작성이나 디지털 서비스 이용에 어려움을 느낌
* 도시농부는 자신의 신청 상태나 근무 정보를 실시간으로 확인하기 어려움
* 전체 과정이 아날로그 방식에 가까워 사용자 편의성이 낮음

## 💡 해결 방향

도시농부플러스는 도시농부와 농가가 직접 플랫폼에서 연결될 수 있도록 서비스 구조를 단순화했습니다.

### 기존 방식

```text
도시농부 교육 이수
→ 전화 신청
→ 문자 확인
→ 전화 또는 문자 회신
→ 농가 매칭
→ 근무 정보 확인
```

### 개선 방식

```text
도시농부 회원가입
→ 교육 정보 확인
→ 농가 모집 공고 조회
→ 원하는 농가에 지원
→ 농가 수락 또는 거절
→ 매칭 확정
→ 근무 정보 확인
```

## 🔄 서비스 전체 흐름

1. 도시농부가 회원가입을 진행합니다.
2. 도시농부는 교육 정보를 확인하고 교육 사이트로 이동할 수 있습니다.
3. 농가는 회원가입 후 농가 정보를 등록합니다.
4. 농가는 필요한 작업 날짜, 작업 내용, 모집 인원을 입력합니다.
5. AI가 농가의 입력 내용을 바탕으로 모집 글을 자동 작성합니다.
6. 도시농부는 등록된 농가 모집 공고를 확인합니다.
7. 도시농부는 원하는 모집 공고에 지원합니다.
8. 농가는 지원한 도시농부의 정보와 경험 횟수를 확인합니다.
9. 농가는 도시농부를 수락하거나 거절합니다.
10. 농가가 수락하면 매칭이 확정됩니다.
11. 도시농부는 농가 정보, 작업 내용, 준비물, 집결 장소를 확인합니다.
12. 근무 완료 후 인건비 지급 상태를 확인할 수 있습니다.

### AI 모집 글 자동 작성

농가는 작업에 필요한 핵심 정보만 입력하면 AI가 모집 글을 자동으로 작성해줍니다.

예를 들어 농가가 다음과 같이 입력합니다.

```text
이번 주 금요일에 사과 수확할 사람 3명 필요하고,
오전 8시까지 와야 해.
장갑이랑 모자 챙겨오면 좋겠어.
```

AI는 다음과 같이 모집 글을 작성합니다.

```text
제목: 사과 수확 작업 도시농부 모집

내용:
이번 주 금요일 오전 8시부터 사과 수확 작업에 참여할 도시농부 3명을 모집합니다.
작업은 사과를 수확하고 정리하는 방식으로 진행됩니다.
장갑과 모자를 준비해오시면 좋으며, 야외 작업이므로 편한 복장으로 참여해주시기 바랍니다.
```

이 기능을 통해 농가 사용자는 글 작성 부담을 줄이고, 도시농부는 작업 내용을 더 쉽게 이해할 수 있습니다.

## 🚀 기대 효과

도시농부플러스는 기존의 전화와 문자 중심의 아날로그 운영 방식을 온라인 플랫폼으로 개선합니다.

이를 통해 도시농부는 교육 정보 확인, 농가 모집 공고 조회, 지원, 매칭 결과 확인, 근무 정보 확인까지 하나의 서비스에서 처리할 수 있습니다.

농가는 AI의 도움을 받아 모집 글을 쉽게 작성하고, 지원한 도시농부의 경험 횟수와 정보를 확인한 뒤 직접 수락 또는 거절할 수 있습니다.

결과적으로 도시농부와 농가가 더 쉽게 연결되고, 농촌 일손 부족 문제 해결에 도움을 줄 수 있습니다.
