# 도시농부플러스 🌱

> 규칙 기반 작성·안내 도구를 제공하는 충북형 도시농부 통합 플랫폼
> 도시농부와 농가를 온라인으로 연결하고, 농가의 일손 모집과 작업 안내를 더 쉽게 만드는 서비스입니다.

**도시농부플러스**는 충청북도에서 운영 중인 **충북형 도시농부 사업**의 신청, 모집, 매칭 과정을 디지털화한 서비스입니다.

현재 도시농부 사업은 농촌의 일손 부족 문제를 해결하기 위한 좋은 정책이지만, 실제 운영 과정에서는 전화, 문자, 수기 관리 중심으로 진행되는 경우가 많습니다.

도시농부는 교육을 이수한 뒤 중개센터에 전화로 신청해야 하고, 농가는 일손이 필요할 때 직접 연락하여 인력을 요청해야 합니다. 이 과정은 참여자에게 번거롭고, 농가 입장에서도 모집 글 작성이나 신청 관리가 어렵다는 문제가 있습니다.

**도시농부플러스**는 이러한 문제를 해결하기 위해 도시농부와 농가가 플랫폼에서 신청, 모집, 지원자 의견 등록, 근무 정보 확인을 할 수 있도록 돕습니다. 통합 백엔드는 중개센터의 심사·최종 매칭·운영 통계와 규칙 기반 모집 글 작성 지원까지 함께 제공합니다.

## 🧩 문제 상황

충북형 도시농부 사업은 도시민이 농촌 일손 부족 문제 해결에 참여할 수 있는 좋은 정책입니다.

하지만 기존 방식에는 다음과 같은 문제가 있습니다.

* 도시농부 신청 과정이 전화와 문자 중심으로 이루어짐
* 교육 이수 후에도 별도로 전화 신청과 매칭 절차가 필요함
* 농가는 일손 모집을 위해 직접 연락하거나 설명해야 함
* 고령 농업인은 모집 글 작성이나 디지털 서비스 이용에 어려움을 느낌
* 도시농부는 자신의 신청 상태나 근무 정보를 실시간으로 확인하기 어려움
* 전체 과정이 아날로그 방식에 가까워 사용자 편의성이 낮음

## 💡 해결 방향

도시농부플러스는 도시농부와 농가가 직접 플랫폼에서 연결될 수 있도록 서비스 구조를 단순화했습니다.

### 기존 방식

```text
도시농부 교육 이수
→ 전화 신청
→ 문자 확인
→ 전화 또는 문자 회신
→ 농가 매칭
→ 근무 정보 확인
```

### 개선 방식

```text
도시농부 회원가입
→ 교육 정보 확인
→ 농가 모집 공고 조회
→ 원하는 농가에 지원
→ 농가의 지원자 선호 의견 등록
→ 중개센터 최종 매칭
→ 근무 정보 확인
```

## 🔄 서비스 전체 흐름

1. 도시농부가 회원가입을 진행합니다.
2. 도시농부는 교육 정보를 확인하고 교육 사이트로 이동할 수 있습니다.
3. 농가는 회원가입 후 농가 정보를 등록합니다.
4. 농가는 필요한 작업 날짜, 작업 내용, 모집 인원을 입력합니다.
5. 규칙 기반 생성기가 농가의 구조화된 입력을 바탕으로 모집 공고 문안 초안을 만듭니다.
6. 도시농부는 등록된 농가 모집 공고를 확인합니다.
7. 도시농부는 원하는 모집 공고에 지원합니다.
8. 농가는 지원한 도시농부의 정보와 경험 횟수를 확인합니다.
9. 농가는 지원자에 대한 선호·비선호 의견을 등록합니다.
10. 중개센터가 심사 결과와 조건을 확인해 최종 매칭합니다.
11. 도시농부는 농가 정보, 작업 내용, 준비물, 집결 장소를 확인합니다.
12. 근무 완료 후 작업 이력을 확인합니다. 임금은 공고의 근로조건 정보이며 서비스가 결제·송금·정산하지 않습니다.

### 규칙 기반 모집 공고 문안 미리보기

승인된 농가는 작물, 작업 유형, 작업일, 시작·종료 시각, 모집 인원, 집결 장소, 준비물, 주의사항을 구조화된 JSON으로 입력해 공고 문안 초안을 미리 볼 수 있습니다.

서버는 외부 LLM을 호출하지 않고 `RULE_BASED_V1` 규칙으로 다음 값을 생성합니다.

* `title`: 작물·작업 유형을 반영한 제목
* `description`: 작업일·시간·인원을 반영한 설명
* `supplies`: 입력 준비물과 작업 유형별 추천 준비물
* `precautions`: 입력 주의사항과 규칙 기반 안전수칙
* `beginnerGuide`: 초보자용 작업 안내

생성 결과는 DB에 자동 저장되거나 공개되지 않습니다. 농가가 검토·수정한 뒤 별도의 공고 생성 API를 호출해야 합니다.

---

### 모집 공고 관리

농가는 공고 초안을 생성·조회·수정·삭제하고 심사를 요청하거나 철회할 수 있습니다. 공개 전 공고 심사와 모집 마감은 중개센터 API가 담당하며, 농가는 진행 중인 공고를 취소할 수 있습니다.

| 내부 상태 | 의미 |
|---|---|
| `DRAFT` | 농가가 수정·삭제할 수 있는 초안 |
| `PENDING_REVIEW` | 중개센터 심사 대기 |
| `OPEN` | 승인되어 지원을 받는 공고 |
| `CLOSED` | 모집 마감 |
| `CANCELLED` | 농가 또는 계정 정리로 취소 |
| `WORK_COMPLETED` | 연결된 근무가 모두 완료된 상태 |

승인·반려·마감 상태 전이는 통합 중개센터 영역에서만 확정합니다.

### 지원자 선호 의견 등록

농가는 지원한 도시농부를 확인한 뒤 선호·비선호 의견과 메모를 등록할 수 있습니다. 이 의견은 수락·거절이나 최종 매칭 확정이 아닙니다.

주요 기능은 다음과 같습니다.

* 지원자 목록 확인
* 선호·비선호 의견 등록 및 수정
* 지원 당시 희망 지역·요일·기간·작업 유형·이동 가능 여부 확인
* 최종 매칭은 중개센터가 담당

---

### 근로계약 및 안전수칙 안내

농가는 근무 시작 전 도시농부에게 근로계약 내용과 안전수칙을 안내할 수 있습니다.

제공 정보는 다음과 같습니다.

* 근무 날짜
* 근무 시간
* 작업 장소
* 작업 내용
* 인건비 기준
* 안전수칙
* 사고 발생 시 연락처

---

### 근무 완료 처리

농가는 작업 시작 후 출결을 최초 등록하고 작업 종료 후 근무 완료를 확정할 수 있습니다. 임금 지급 상태 등록과 정산 처리는 제공하지 않습니다.

## 🤖 AI 기능

현재 외부 LLM API는 호출하지 않습니다. 모집 공고 미리보기와 작업 안내는 응답에 `RULE_BASED_V1`을 표시하는 규칙 기반 생성기이고, 행정 상담은 `RuleBasedSupportAnswerGenerator`가 키워드에 따라 안내 문구와 공식 확인 필요 여부를 반환합니다.

## 규칙 기반 모집 공고 작성 지원

농가가 구조화된 작업 정보를 입력하면 저장 가능한 길이 범위 안에서 모집 공고 문안 초안을 생성합니다.

입력값은 다음과 같습니다.

* 작물
* 작업 종류
* 작업 날짜
* 작업 시작·종료 시각
* 모집 인원
* 작업 장소
* 준비물
* 주의사항

출력값은 다음과 같습니다.

* 모집 제목
* 모집 본문
* 준비물
* 주의사항
* 초보자 안내 문구

## 규칙 기반 작업 안내

확정 근무의 작업 유형·준비물·주의사항 스냅샷을 바탕으로 작업 절차와 안전 안내를 생성합니다.

주요 기능은 다음과 같습니다.

* 작업 절차 요약
* 필요한 준비물 안내
* 복장 안내
* 안전수칙 안내
* 초보자 주의사항 안내

---

## 규칙 기반 행정 상담

활성 회원은 교육, 농가 공고 작성, 작업 준비, 공고 지원·취소에 관한 질문을 보낼 수 있습니다. 서버는 키워드 규칙으로 답변을 생성해 사용자별 이력으로 저장합니다. 계좌·송금·결제·정산·지급 질문은 처리하지 않고 개인정보 입력을 경고하며 `officialConfirmationRequired=true`를 반환합니다. 규칙에 맞지 않거나 행정 판단이 필요한 질문도 공식 담당자 확인 대상으로 안내합니다.

현재 규칙이 안내하는 범위는 다음과 같습니다.

* 교육·이수증 안내
* 농가 모집 공고 작성 안내
* 작업 준비물·복장·안전 안내
* 공고 지원·취소 안내
* 금전 관련 요청 거부와 공식 담당자 확인 안내

---

## 📢 알림 범위

알림함, 푸시, 문자, 알림톡은 현재 프로젝트 범위에서 제외했습니다. 화면은 각 조회 API의 최신 상태를 사용하며 알림 기능이 구현된 것으로 간주하지 않습니다.

## 🚀 기대 효과

도시농부플러스는 기존의 전화와 문자 중심의 아날로그 운영 방식을 온라인 플랫폼으로 개선합니다.

이를 통해 도시농부는 교육 정보 확인, 농가 모집 공고 조회, 지원, 매칭 결과 확인, 근무 정보 확인까지 하나의 서비스에서 처리할 수 있습니다.

농가는 규칙 기반 작성 도구의 도움을 받아 모집 글을 쉽게 작성하고, 지원한 도시농부의 경험 횟수와 희망 조건을 확인해 선호 의견을 남길 수 있습니다. 최종 심사·매칭·운영 통계는 통합 중개센터 기능으로 연결됩니다.

결과적으로 도시농부와 농가가 더 쉽게 연결되고, 농촌 일손 부족 문제 해결에 도움을 줄 수 있습니다.
